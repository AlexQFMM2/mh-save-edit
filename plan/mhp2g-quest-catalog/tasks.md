# 任务规格

所有任务由本次实现者在 mh-save-edit 串行执行；无并行代理授权。共享资源为类型、IPC、共享 UI 与 P2G 运行库，后续阶段必须等待前序验收。

| 波次 / ID | 输入、工作与输出 | 验收与交接 |
| --- | --- | --- |
| B0 / T-001 | 接入核查及已忽略研究快照 → 固定研究输入、来源 manifest、当前数据库基线和计划目录 | 校验哈希；最新规则可追溯；构建不依赖宿主机 |
| B1 / T-002 | T-001 输入 → 502 条候选、中文校对、条件结构及旧任务引用对照 | 日文身份唯一；旧出没和道具记录逐条有结论；无悬空关系；交接 prepared evidence |
| B2 / T-003 | T-002 evidence 与现有 P2G 库 → 构建器、审计器、独立查询仓库、共享类型和 IPC | 新目录构建、错误输入拒绝、重复结果一致；合成查询/IPC 测试通过 |
| B3 / T-004 | T-003 数据接口 → 任务入口、共享页面及 P2G 分节组件、双向关联迁移 | 搜索命中、定位、未知值、一级抽屉和异步状态通过；页面不侵入组件样式 |
| B4 / T-005 | T-003/004 → 数据审计、回归、界面验收、安装与交接文档 | 计划约定计数与特例通过；typecheck/build；三作哈希不变；私有边界检查；备份可回退 |

每项 Parallel candidate：no。失败时保留原库和已冻结输入，在新输出目录重建；不在应用运行中执行数据库迁移。
