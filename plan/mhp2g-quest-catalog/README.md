## 目标与证据

实现 450 个本体任务及 52 个 Wiki 配信任务的中文图鉴、搜索筛选、详情及道具／怪物双向关联。原生调查见 [接入核查](../../docs/mhp2g-quest-preflight.md)。采用最新的事件 v1、奖励 v3、出场 v1 和 closure audit，旧快照仅保留历史。

## 决策与边界

日文与原生身份定关联，GU 官汉核对后优先；旧汉化只作为校对参考。配信采用来源身份，缺失数字保持空值。静态条件保留 AND／OR 和条件语义，不扩展存档修改、实时可接判断、AI 模拟或整场概率。复用共享页面，P2G 独立仓库与 itemId；三作数据不变。公开目录只保存代码、合成测试和说明，研究输入与输出保持私有。

## 执行与验收

依次执行 [任务规格](tasks.md) B0 → B4；[进度表](taskList.md) 只记录状态。本体身份、翻译、关系端点通过审计后接入 UI。验收覆盖数据计数、特殊条件、身份隔离、旧引用、抽屉导航、异步状态、旧三作回归、类型检查与构建。

## 安装、回退与风险

在新目录构建并验证，备份当前 P2G 库后安装；不自动关闭应用，已有连接下次启动加载。回退恢复备份库。三作库不需回退。用户已授权本地实现，未授权 P2G 公开资产发布。现存未提交怪物图鉴修改属于基线，不能回滚。
