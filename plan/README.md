## 当前证据与已知限制

[v0.1.11](../docs/releases/v0.1.11.md) 已公开发布；发布前本地回归为 79 个测试文件、471 项通过、7 项按环境跳过，类型检查、构建及编译后的 GU Worker 检查通过。[对应 GitHub Actions](https://github.com/AlexQFMM2/mh-save-edit/actions/runs/38031104206) 的检查与 Windows 打包成功。这些是该版本已有的验证记录，本次归档只整理文档与链接。

以下边界随历史计划一并保留，不再排为待办：

- 五格式完整真实样本、特殊装备/猎猫/幻化的游戏内重开，以及全站 Windows 高 DPI/视觉/性能矩阵尚未完整验证。
- 技能抽屉的护石关系仍只读；账号、邮箱和在线广场未接入当前离线交付。
- 动作值原生字段、精确技能公式、MH4G 发掘/护石自然规则的未知部分维持原证据等级。

`plan/` 已由 Git 跟踪，归档不会改成私有目录；这里只保留计划文字和代码链接。真实存档、截图、原生文件、研究数据库及审计中间产物仍留在原有私有或忽略路径。
