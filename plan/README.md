## 当前证据与已知限制

[v0.1.12](../docs/releases/v0.1.12.md) 与运行资源 v5 已发布；[对应 GitHub Actions](https://github.com/AlexQFMM2/mh-save-edit/actions/runs/38373223991) 的检查与 Windows 打包成功。P2G 应用侧回归、真实资料核对及用户修改实测依据见[验收记录](../docs/mhp2g-acceptance.md)。这些证据属于已交付修改器，尚未验证的游戏中文补丁按新计划独立验收。

以下边界随历史计划一并保留，不再排为待办：

- 五格式完整真实样本、特殊装备/猎猫/幻化的游戏内重开，以及全站 Windows 高 DPI/视觉/性能矩阵尚未完整验证。
- 技能抽屉的护石关系仍只读；账号、邮箱和在线广场未接入当前离线交付。
- 动作值原生字段、精确技能公式、MH4G 发掘/护石自然规则的未知部分维持原证据等级。

`plan/` 已由 Git 跟踪，归档不会改成私有目录；这里只保留计划文字和代码链接。真实存档、截图、原生文件、研究数据库及审计中间产物仍留在原有私有或忽略路径。
