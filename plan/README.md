## 文档与研究边界

`plan/` 已由 Git 跟踪，归档不会改成私有目录；这里只保留计划文字、代码链接和私有证据位置。原生输入、存档、截图、研究数据库、manifest、crosswalk 与审计中间产物不随归档移入公开仓库。发布范围以 [AGENTS.md](../AGENTS.md) 和明确授权为准。

已有功能按具体问题维护。当前能力及接手方法以[项目 README](../README.md)、各作说明和最新用户指令为准。历史真实样本、高 DPI／视觉性能、未知动作或技能字段等未完整验证的部分保留原边界，不因计划整理自动变为已验收。
