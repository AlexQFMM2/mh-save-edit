## 目标与证据

接入 168 颗珠的独立图鉴，复用现有装饰品列表、分页、孔位／技能筛选、详情和一级抽屉。基础证据见[交接](../../docs/mhp2g-decoration-handoff.md)：中日文名、图标、身份、281 条技能点、192 套配方与 597 条材料已核实，技能图鉴已可用。

## 方案与边界

以最新含技能的 P2G 库为固定基线，追加装饰品身份和原道具用途的显式索引，复用已核实装备资料，不复制三作数值。P2G 使用 `itemId`，旧三作保留 `saveId`；材料关联传完整道具身份。提供中日文及关联材料／技能搜索、命中说明、道具与技能双向关联；旧技能装备链接继续解析。未安装装饰品资料的技能库保持原技能关联详情。

稀有度、制造费用和解锁条件未证实，显示“未收录”；不以买价代制造费，不开放存档写入、配装、完整防具或武器图鉴。已有道具／怪物／任务／技能表和三作、词典库保持不变。共享组件遵守职责、全局样式令牌及唯一一级 portal 抽屉约定。
