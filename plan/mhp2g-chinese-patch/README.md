## 2026-10-20 test.2 启动故障与 test.3 修复

已确认两项故障：

- 当前图鉴基线为 `catalog-armor-v1`。名称输入需合并冻结 `localization-v4`、武器 `weapon-name-review-v1/names.json`、防具 `armor-catalog-v1/name-review.json` 及既有技能审阅结果，不能用较早输入覆盖后续审阅。相关入口见中文资料说明和技能图鉴文档。
- 图鉴和游戏补丁共享选定译文及来源。仅编码、控制码序列化、换行和资源布局等目标格式处理由补丁输出层负责；新增对话按同一可追溯原则维护，不另建一套脱节的名称词典。
- 字体生成器负责字符映射、字形、度量和许可；PRX 负责游戏匹配、挂接时机、外置文本／字体加载及缓冲生命周期；离线工具负责译文编码、长度和引用校验以及插件包组装。复用 PPSSPP 的插件加载，不另建通用插件框架。ISO 写回器只在启用后备路线时实施。
- 接管哪一层文本读取由实际证据确定：原生资源加载、解码后文本表或文本查询入口均可评估，优先选择最小可靠入口。只有经过封装／加密层时才处理对应规则；无论选哪一层，都要校验指针、长度、缓存、内存边界及未替换文本的原版行为。
- 优先通过 `sceFontOpenUserFile`／`sceFontOpenUserMemory` 接入插件自带 PGF 并复用现有绘字流程，具体接口由导入、文件回调与容量证据决定。只有证据表明此路径不能满足需要时，才评估点阵字库与字形读取替换。思源黑体是候选来源，转换器必须验证实际字符映射，不能默认旧 `ttf2pgf` 支持任意新增汉字。
