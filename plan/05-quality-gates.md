# 质量门禁、迁移策略与完成定义

## 1. 迁移策略

旧项目保留为独立参考仓库：

| 来源 | 优先迁移内容 | 不迁移内容 |
| --- | --- | --- |
| `mh3u-se` | 3DS/Wii U 格式、端序、字段、数据构建、配装测试 | Qt UI、qmake、窗口类 |
| `mh4g-se` | Blowfish、28 字节实例、发掘/护石/猎虫、SQLite、配装规则 | Qt UI、OpenSSL 运行时耦合 |
| `mhgu-xx-se` | GU/XX 格式、36 字节实例、猫猫、原生 ID、合法性规则 | Qt UI、平台混合 adapter |
| `mhed-platform` | OpenAPI、认证、邮箱、广场、审核与服务端夹具 | Go 服务复制到桌面端 |

每个迁移单元遵循：

```text
确认旧行为和来源证据
→ 提取与框架无关的输入/输出夹具
→ 用 TypeScript 实现纯核心
→ 新旧实现对拍
→ 接入统一 API
→ 最后接 UI
```

没有测试证据的历史行为不能仅因“旧程序这样写”就视为正确。

## 2. 测试分层

### 单元测试

- 二进制端序、位字段、字符串和边界工具。
- 各格式 detect/read/patch/checksum/encrypt。
- 图标键生成和显式映射。
- 数据 repository 查询与 ID 隔离。
- 配装计算、珠子占孔、技能发动和排序。

### 黄金夹具测试

- 私有真实样本留在 `research/`，只在本地执行。
- 公开仓库只放去隐私的最小合成夹具和预期 diff。
- 每种格式至少覆盖空/普通/边界角色槽和丰富装备样本。
- MHXX 在真实样本覆盖不足前不能标记稳定。

### 集成测试

- Electron 主进程文件打开、IPC、保存和重新打开。
- SQLite + 图标包完整性。
- 图鉴选择 → 配装计算 → 生成实例 → 装备箱写入。
- 在线响应 → 本地导入 → 本地重新计算，网络失败保持原状态。

### 性能测试

- 大型图鉴查询和虚拟列表。
- GU/XX 自动配装搜索、取消和内存上限。
- 一万条广场列表分页与筛选。

## 3. 存档安全硬门禁

以下任何一项失败都禁止发布对应格式：

- no-op 保存不是逐字节一致。
- 修改一个字段改变了未声明的明文字节范围。
- 损坏/截断/错误游戏文件被识别为合法。
- 保存中断可能覆盖原文件或留下半写目标。
- 未知装备字节在编辑后丢失。
- 加密格式不能由独立实现重新读取。
- 格式身份提示与实际 adapter 不一致。

## 4. 数据硬门禁

- 正式实体 ID 唯一且来源可追踪。
- `save_id` 与 `dex_id` 没有混用。
- 所有图标引用存在，且同名跨游戏资源不串用。
- 装饰珠通过 item 图标关系解析。
- 护石装备图标和未鉴定 Charm 道具图标分开。
- SQLite 与 manifest 同版本，篡改或遗漏时应用明确拒绝加载。

## 5. 配装硬门禁

- 配装模型不保存装备箱格号。
- 自动搜索不会仅搜索当前装备箱，除非用户主动开启 `owned-only`。
- 自动结果全部经过正式计算器复核。
- 写入装备箱是全有或全无事务。
- 不具备生成规则的动态实例不会被自动创建。
- 导入不兼容数据版本不会静默换 ID。

## 6. 阶段完成定义

一个阶段只有同时满足以下条件才算完成：

- 计划中的用户闭环可以从 UI 实际完成。
- 类型检查、单元测试、集成测试和构建全部通过。
- 新增格式/实体有来源说明、manifest 和边界测试。
- 错误、空状态、取消和恢复路径已经验证。
- README 和支持矩阵与真实能力一致。
- 没有把真实存档、账号密钥或受限研究输入加入公开提交。
- 相关旧项目行为已对拍或明确记录差异原因。

## 7. 推荐首批迭代

### 迭代 A：基础协议

- 完成五格式 ID、capabilities、错误码和 binary 工具。
- 建立测试目录、私有夹具路径和 CI 门禁。
- 将当前三个占位 adapter 拆为格式注册表，不实现盲目兜底。

### 迭代 B：数据与图标纵切

- 先完成 MH3G 武器/防具/道具/护石/珠子和图标。
- 做最小图鉴页面。
- 固化通用 schema 和 importer 后接入 MH4G、MHGU/XX。

### 迭代 C：MH3G 双格式存档纵切

- 同时迁移 Citra 3DS 和 Cemu Wii U，验证同内容、不同格式的 adapter 边界。
- 完成玩家、道具箱、装备箱、保存事务和格式提示。

### 迭代 D：其余存档

- 先 MH4G 加密格式，再 MHGU Yuzu，最后用新增真实样本收口 MHXX Citra。

### 迭代 E：配装

- 先纯计算器和手动配装，再自动搜索，最后接五格式物化写入。

此后才进入 UI 美化和在线复用，避免界面返工掩盖底层格式问题。
