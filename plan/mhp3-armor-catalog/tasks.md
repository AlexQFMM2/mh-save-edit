# 任务规格

Owner／集成负责人均为当前实施者，仓库 mh-save-edit；全部串行，无并行代理。前一波退出证据记录后进入下一波。

| 波次／任务 | 输入及职责 | 输出和验收 | 依赖／共享资源 |
| --- | --- | --- | --- |
| B0／T-001 | 当前源码、完整 P3 库、冻结原生与技能输入 | 工作区快照、六库哈希及旧表指纹，恢复基线 | 无；保留既有用户改动 |
| B1／T-002 | 原生访问器、记录、制作消费者及 P3 Wiki | 属性／强化／材料契约、取得分类、差异与未知记录 | T-001；只读宿主，研究成果私有 |
| B1／T-003 | 原文、gu-pass-02、Wiki 明确成员 | 逐条名称及套装审阅，独立身份全覆盖 | T-002；不按前缀猜分组 |
| B2／T-004 | 冻结资料、当前完整库副本 | 离线构建器、schema、repository、IPC，合成测试及全量数据审计 | T-003；数据库、共享类型串行 |
| B3／T-005 | T-004 接口、共享防具页 | 完整列表／套装／详情、双向关联、旧链接与旧库兼容 | T-004；共享 UI 与样式串行 |
| B4／T-006 | 候选库、合成测试、真实资料 | 类型／测试／构建、两尺寸验收、备份安装、交接恢复记录 | T-005；安装前核对基线，失败恢复 |

验收包括来源哈希变化、重复／越界身份、端点错误、同名件、负点、复制标记、多配方、男女／职业互斥、未知状态、缺库／重试、选择不重查、历史滚动、单层抽屉与焦点恢复。正常目录核心属性及材料端点不得缺失；特殊条目的未知取得保留。完成必须链接实际证据，不以勾选代替。
