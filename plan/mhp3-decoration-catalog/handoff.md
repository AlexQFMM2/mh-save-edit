# P3 独立装饰品图鉴交接

更新：2026-10-24。状态：实现与本地验收完成，本次提交源码。用户已查看并认可前一道具首版，本轮按要求直接接入独立装饰品。执行为单代理串行。最新用户指令为更新交接并提交 GitHub，不生成 Release。

## 交付

入口为 **P3 → 资料 → 装饰品**。沿用 P2G 的列表、工具栏、技能／孔位筛选、分页、详情与材料组件；新增 P3 名称来源／说明／收录边界组件，以及只展示已收录装饰品技能点的一级技能关联抽屉。数据读取已有 `data/mhp3.sqlite`，没有新增数据存储或重复翻译，也无需安装新运行资产。

164 件装饰品、198 条配方、514 条材料与道具视图逐项一致。提供中文／日文／别名／原生编号／中英日技能／材料搜索，显示技能或材料命中原因，支持 1～3 孔及 98 个技能筛选。P3 技能筛选包含负点，按点数排序时完整保留正负值。同名珠仍以各自编号区分，保留孔数和所有技能标签。

道具正文可打开装饰品抽屉；装饰品正文可打开材料道具或技能关联抽屉。抽屉内下一次关联点击先关闭，再定位对应图鉴；技能无独立图鉴，关闭后跳转装饰品技能筛选。同一时刻只保留一个抽屉。列表选择保持滚动且不重查，前进后退恢复选中；筛选、列表和详情错误均可重试。

## 实现与边界

- `api/catalog/p3DecorationRepository.ts`：现有道具库的只读投影，复用 P3 item repository 的已验证字段；无迁移或更新语句。
- `DecorationCatalogGameId`、装饰品 schema／身份助手及 IPC：只扩大装饰品接口，保留原生 itemId；全局 CatalogGameId 不变。
- 共享装饰品页面及组件：P3 路由开放，不挂载其他作品的技能详情服务，不提供存档写入。技能显示组件使用明确 class，父页面不覆盖内部 DOM。
- `P3DecorationInfo`、`P3DecorationSkillDrawer`：各自 tsx/css，使用全局字号、数据色和滚动规则。技能抽屉复用列表与分页，没有复制业务数据。
- `tests/mhp3DecorationCatalog.test.ts`、`mhp3DecorationUi.test.tsx`：新增 9 项合成测试；既有 P3 道具／首页／IPC 测试同步验证新增入口和关联去向。

制造费用、配方出现条件、技能发动阈值及完整效果仍未确认。技能关系抽屉只表达已收录的装饰品点数；完整技能图鉴、其他装备图鉴、配装和存档编辑仍待专项。前一轮命名要求不变：同用途采用后作根名，数值全部保留 P3 原值；未知字段不以 GU 补齐。

## 验收

- 真实库全量 164 件：名称／日文、图标、孔数、每项正负技能点、卖价、稀有度、说明及全部材料数量与道具视图相同。198 配方、514 材料关系、98 技能筛选／排序和全量名称、日文、编号、材料反查通过。
- TypeScript 类型检查和生产构建通过。
- Vitest 全量：127 个文件、860 项通过；3 文件／8 项原有跳过，无失败。新增测试涵盖同名珠、负点、替代配方、别名与材料搜索、非法身份、抽屉路径、技能服务隔离、滚动／历史及筛选失败重试。
- 真实资料使用生产 renderer + Chromium + 只读 repository 适配器，1440×900、1024×768 均验证中文、同名珠标签、材料双向路径、技能抽屉关闭后筛选、两种配方、滚动保持、分页、前进后退、英文技能下拉检索、图片与内容宽度，无 renderer 异常。四作装饰品页实际回归通过（168／196／289／242 件）。
- 五作运行库及词典共六个文件 SHA-256 与本轮开始完全相同；未使用宿主连接，未重建或覆盖数据。私有输出与运行资料仍被忽略，无暂存文件。
