用户在本地道具首版查看后确认可用，要求直接接入装饰品。现有 P3 运行库已含 164 件装饰品和 198 条制作路线，名称、孔数、完整正负技能点、材料及图标均已核对。本轮复用该库与既有装饰品页面，建立独立只读查询视图，不新增第二套数据或重建译名。

交付独立路由、原生编号身份、名称／日文／别名／技能／材料搜索、孔位与技能筛选、完整详情、替代配方，以及与道具互通的一级抽屉。技能关联仅展示已有装饰品技能点和关联珠；发动阈值与完整效果尚未收录，不开放完整技能图鉴或存档写入。原有翻译要求继续适用，同名珠保留完整正负点数标签。

实施依赖上轮已安装的 mhp3.sqlite 和词典，使用独立 DecorationCatalogGameId，不扩大全局 CatalogGameId。四作库、P3 库和词典均保持原样；无迁移或宿主查询；实施阶段未提交，最新用户已授权源码提交与推送，本轮仍不发行。风险主要是扩大公共身份类型及关联路径；以类型检查、针对性测试和四作回归控制。无当前阻碍，按验收完成交付，不作工期承诺。

验收：全量 164 件／198 配方与道具视图逐项一致；同名珠、别名、技能和材料命中原因、负技能、URL与滚动、错误重试、正文打开抽屉与抽屉关闭后定位；P3 未支持服务隔离；类型、生产构建、真实资料 1440×900／1024×768、四作回归及数据哈希不变。回滚仅撤回本轮接口与路由代码，运行数据无需恢复。私有报告保存在 research，计划只保存结论与入口。
