# 任务规格

负责人／集成人为当前实施者，仓库 mh-save-edit。全部串行，无多代理或并行候选，公共类型和组件构成共享文件边界。

- T-001：复用资料与独立 API。输入 P3 已验收道具库，输出独立装饰品身份、查询 repository、IPC；文件 api/catalog、desktop、ui/env。依赖无；验收 164 件／198 路线与道具一致，中文／日文／别名／技能／材料查询、端点与跨作隔离，无数据库写入。

## B1

- T-002：共享页面与一级关联。依赖 T-001；输出装饰品路由、列表、筛选、详情、技能与材料关联；文件 ui/pages、ui/components。验收同名珠完整技能点、配方与孔位、错误重试、列表滚动和历史、抽屉关闭后定位，不嵌套、不生成未接入路由。新组件独立 tsx/css，水平 SearchableSelect 和全局令牌。

## B2

- T-003：验收与交接。依赖 T-001／002；输出合成测试、全量私有一致性报告、两尺寸真实资料验收、四作回归和文档。验收类型／构建／测试通过，六个运行库（五作＋词典）哈希不变，私有产物无 Git 跟踪。本计划 handoff 记录最终证据和边界，不提交或发布。
