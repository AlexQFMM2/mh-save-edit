## 目标与范围

基于[核查结论](../../docs/mhp2g-skill-preflight.md)接入 99 个技能系统、213 条有 Wiki 依据的发动技能及胴系统倍加特殊规则，支持中文／日文搜索、方向与来源筛选、复合效果及装备技能关联详情。保留 Wiki 阈值和效果来源；4 条用途未确认的日版负面技能文本不列入正常目录。GU 仅用于名称，不复制机制。只修改 P2G，保持三作和现有道具／怪物／任务行为。

复用共享技能页面与核心组件，P2G 使用独立 repository、原生技能 ID 和显式装备资料键。关联珠复用已核实道具名称、图标及身份，追加原生孔位、技能点和配方；防具提供已有资料中的名称、部位、孔位和技能点，可未译名称保留日文。关联详情只展示已核实字段，不宣称完整装备图鉴、存档编码或配装支持。正文唯一一级抽屉，抽屉内点击材料／技能关闭后跳转。P2G 无护石。
