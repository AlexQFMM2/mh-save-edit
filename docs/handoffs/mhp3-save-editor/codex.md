2026-11-23，本地交付。按计划 r1 实现，分支为 `feat/mhp3-save-editor`，基线为已核实的 `release` 提交 `f3e4cce01ae0f73b20a4a8a4aadc39e44665e328`。计划位于仓库同级的 `../plan/mh-save-edit/mhp3-save-editor/`。游戏侧验收由用户进行。

## 使用范围

- 从 P3 总览进入「打开存档」，选择「P3 · PPSSPP」，再选择原版日版 `ULJM05800/MHP3RD.BIN`。同目录需要 `PARAM.SFO`。角色名、性别和游戏时间只读，猎人等级显示未知，金钱可修改。
- 道具箱、猎人装备箱按取得的收纳书显示 800、900 或 1,000 格。两箱都支持全箱搜索、复制、清空、换位、CSV 和同格式完整备份。正常替换候选使用本作原生身份，完整备份保留有符号道具数量、特殊格和原始装备记录。写入范围限于已开放箱页。
- 装备箱支持原生武器、防具和手动护石，以及强化和装珠。已穿戴装备按兼容部位修改，删除或跨部位替换前需在游戏内卸下。换位会维护穿戴引用及 45 套登记预设。自然强化上限、超孔及护石随机组合标记与结构校验分别呈现。
- 编辑进入会话历史，支持撤销和重做。保存成对备份、写回、解密校验，写入中断由日志恢复。另存为在所选父目录下创建新的 `ULJM05800`，一同复制现有图片。随身背包、HR 写入、猫与配装属于后续范围。

## 本地资料与恢复

运行需要完整的本地 `data/mhp3.sqlite` 与 `data/mhp3-save-profile.json`。当前格式资源由 `tools/mhp3/build_save_profile.py` 从三份固定指纹的私有输入构建，包含封装参数和 1,131 条原生防具强化上限。已核对生成文件与已安装文件逐字节一致。成功 manifest 与生成文件在 `../research/generated/mh-save-edit/mhp3-save-profile-20261123-v1/`。格式资源和 P3 内容库按现有本地授权管理。

从已有私有输入恢复时，选择新目录并在安装前核对输出文件指纹。退出相应本地应用后安装格式资源。

```bash
python3 -B tools/mhp3/build_save_profile.py \
  --research ../research \
  --output ../research/generated/mh-save-edit/<新目录>/mhp3-save-profile.json
```

## 运行资料与公开包

2026-11-23 用户授权扩大运行资源包，P3 数据库、存档格式资料与 474 张原生图标随运行资源 v7 公开发行（[说明](../releases/runtime-assets-v7.md)）；v0.1.16 起 Windows 包内置这些文件，P3 图鉴与存档编辑开箱可用，不需要再手动放文件。

源码开发按 ZIP 原目录结构解压到仓库根目录。CI 校验固定 SHA-256、六份数据库、两份存档格式资料、2,874 张图标与应用图标；P3 的库完整性、词典身份指纹、schema 与图标存在性在 `tools/audit_runtime_catalog.mjs` 中单独核对，打包前后文件身份由 `tools/runtime/verifyPackagedRuntime.mjs` 比对。

目录解析见 `api/catalog/ipc.ts` 的 `resolveCatalogDataDir`：打包后读 `resources/data`，开发读仓库 `data/`，两者都可用 `MH_SAVE_EDIT_DATA_DIR` 覆盖。若只替换其中一部分资料，图鉴与存档共用同一路径，必须成套替换。
