# P3 武器图鉴：数据契约、构建与恢复

本地猎人武器图鉴覆盖 12 类、987 个独立原生身份。默认目录依据原生生产、初始装备和本作独立资料的鉴定取得，再沿完整升级图计算可达性；不是把 987 个名称槽直接当作正常武器。当前正常目录 987，特殊用途／取得未确认各 0，保留这两种筛选及全部范围。

P3 资料库、译文和原生 PNG 仅限本地。公开仓库只保存构建器、接口、页面、合成测试及本文，不因本次构建而扩大公开发行授权。

## 身份与能力

`WeaponCatalogGameId` 在武器领域允许 `mhp3`，通用 `CatalogGameId` 不变。内容键为 `mhp3:weapon:<nativeType>:<nativeId>`；没有 Dex／存档身份。四个既有查询通道按 schema 分派到 `P3WeaponCatalogRepository`，preload 保留白名单。旧防具版资料库访问武器时明确提示未安装，其他领域继续工作。

## 采用的来源与边界

最高依据为日版 P3 的 EBOOT／解密 ELF：SHA-256 分别为 `9a4142cbe12086f538046633f59cc9b2bbf024c91b16cbe9710078d1cef91fb5`、`755e5d84262c3bb30635b32deffab11a66de118f501e4ac105f503308be8b950`。独立参考为冻结的 P3 Wiki 各类型页、旋律页 117 和弹药页 61；原始 HTML、逐字段冲突、名称 crosswalk、探针与错误记录在私有专题 `research/mhp3/weapon-catalog-20261028/`。

- 原生消费者验证了记录身份、稀有度、攻击、防御、有符号会心、孔数、属性／异常、基础和匠斩味、武具玉强化、部件攻击与费用、生产和升级配方、端材输出及完整派生。
- 武器行长：近战 28 字节，远程 80 字节。`0x885c144` 分派记录，`0x885b8cc` 读取稀有度，`0x885dca8` 读取孔数，`0x88a7af0` 后的分支读取有符号会心。字段偏移和独立比对见私有契约，公开构建器再次解码并校验核心字段。
- 近战攻击消费者 `0x885e934`、远程 `0x885c898` 将攻击强化与基础值分开。强化为基础攻击加 15；枪管另外加基础攻击整除 15（轻弩）或 10（重弩）。弓不套用枪管规则。武具玉材料和费用由原生 getter 验证，列表和树始终使用基础值。
- 斩味消费者 `0x88a7ebc` 和 `0x88a7f60` 读取 40 组累积阈值，基础／匠长度上限分别为 `min(400,150+50*code)`／`min(400,200+50*code)`。基础与匠分别保存七段数组，紫斩为 0，不能把参考图上的不同色段静默覆盖原生值。
- 生产表 `0x899d480` 共 297 路线，升级 dispatcher `0x897d958` 结合 `0x885f710`／`0x9cd7e74` 给出 820 条有序边。每行四组材料和三组端材输出方向独立。生产费为基础费乘 1.5 向下取整，升级费为基础费；不能据此推断商店或出售可用性。
- 原生图中没有实际跨类边，但模型保留跨类能力；双剑 82→6、狩猎笛 85→71 的递减编号边完整保留。最终形态由完整出边计算，不按编号大小判定。33 条鉴定路线采用本作独立资料，费用、数量及概率未知保持空值。
- 铳枪原生炮击类型按“通常／扩散／放射”映射。斩击斧负的属性字段属于瓶，不能取绝对值放入基础属性；瓶数值／剑模式属性比较明确采用 P3 Wiki。
- 弩装填／反动／偏移有原生文本交叉绑定；35 列弹药、速射及蹲射采用逐项核对的本作资料。原生弹药位到道具枚举尚未完整解析。需技能弹药不计入基础容量，完全不可用的弹药不产生反向“可用”关系。速射补正不是已验证原生伤害公式。
- 弓四段蓄力区分基础、装填数 UP 和缺失段；曲射、瓶可用性及强化采用本作资料。笛音色对应 117 行旋律／效果，包含替代旋律和同音列的同时效果。时长、笛吹名人、重奏延长／重新计时来自 P3 Wiki，不声称已解析原生计时公式。
- 573 个 GU-pass-02 用词候选经类型／系列审阅采用，其余 414 个为项目译名；保留日文、别名和译名来源。同名不合并。没有借用后作数值、完整任务解锁判定或存档合法性结论。
- 84 张图标来自本作选择函数、坐标、稀有度调色板和透明度；两条独立解码路径的 RGBA 一致，24×24 PNG 使用内容哈希。游戏画面对照未完成。

## 离线扩展库

构建入口：`tools/mhp3/build_weapons.py` 与 `weapon_schema.sql`。只读完整防具版副本和已审阅冻结输入，无网络、宿主机探查、词典重建或自动安装：

```bash
python3 -B tools/mhp3/build_weapons.py \
  /path/to/complete-armor/mhp3.sqlite \
  /path/to/frozen/weapon-input.json \
  /path/to/frozen/input-icons \
  /path/to/new-private-output
```

输出目录必须不存在。输入契约 `mhp3-weapons-input-v1` 保存完整基库 SHA-256、原生程序 SHA-256、审阅状态、来源版本、类型、武器、配方、边及图标绑定。补充图标路径不能逃逸输入目录。失败生成 `FAILED.txt`，不生成成功 manifest。

追加表：`p3_weapon_types`、`p3_weapons`、`p3_weapon_recipes`、`p3_weapon_materials`、`p3_weapon_edges`、`p3_weapon_item_links`。配方目标、原生类型、材料／端材及弹瓶用途有外键；关系顺序和替代路线独立保留。固定专属详情使用 JSON。运行库剔除研究用原始十六进制、旋律 HTML／行号等，保留功能所需来源。`meta.weapon_schema=mhp3-weapons-v1`，`weapon_data_version` 为冻结输入内容哈希。

构建校验身份范围、类型绑定、核心原生值、基础／强化分离、斩味形状及上限、材料和图端点、专属可用性、图标像素文件哈希、SQLite 完整性及所有旧业务表指纹。基库和既有 metadata 不得意外变化。只在本作新增武器，不重建道具词典，不改其他作品。

## 页面与关联

共享页负责查询、URL、分页和组合；`P3WeaponDetail` 负责机制与强化比较，`P3HuntingHornDetail` 负责音色／旋律，`P3WeaponRecipeList` 同时服务武器详情与道具反查。复用核心属性、斩味条、列表、关系、派生画布、平移缩放、小地图和键盘定位。P3 斩击斧专属类型在显示适配层转换为共享页的瓶武器类别。

中文／日文／别名／图鉴键和材料搜索均通过只读 repository；纯数字／十六进制查询匹配原生编号。关联命中显示原因。选择条目不重新加载列表或树，列表滚动保留；更换武器时详情回到顶部。目录范围与前进后退保存在 URL。正文关联开一级抽屉，抽屉内关闭后定位，Escape 恢复触发焦点。页面没有 P3 存档写入或配装入口。

## 验证与恢复

```bash
python3 -B -m unittest discover -s tests -p 'test_mhp3_*.py'
pnpm typecheck
pnpm exec vitest run --exclude '**/.runtime-assets/**' --maxWorkers=2 --minWorkers=1
pnpm build
```

公开测试使用合成行、图像和关系，覆盖缺旧库能力、混合身份拒绝、负会心、替代配方、空鉴定数量、回向和跨类图、基础值排序、技能弹药、前进后退与抽屉。真实审计、完整 Electron preload／IPC 和两个窗口尺寸的截图留私有。具体结果、候选位置和未完成的平台验收见[专题交接](../../plan/mhp3-weapon-catalog/handoff.md)。

安装前退出应用并关闭 SQLite 连接，验证候选成功 manifest、audit SHA-256、库及图标哈希。备份当前完整库；将候选复制到同目录临时文件后原子替换 `data/mhp3.sqlite`，补入哈希 PNG，不删除其他模块图片。重启验证新旧图鉴、关系及其他五库哈希。失败时退出应用并用原备份原子恢复；新增图标可保留，不能删除已被其他模块使用的哈希文件。P3 的安装不替换词典。
