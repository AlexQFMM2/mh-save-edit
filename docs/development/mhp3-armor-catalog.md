# P3 本地防具图鉴契约

P3 防具为只读领域，不扩大通用 `CatalogGameId`，也不提供配装或存档身份。运行对象沿用 `p3_skill_armors`，唯一键为 `mhp3:armor:<nativeType>:<nativeId>`；类型 0～4 分别为胸、腕、腰、腿、头，编号上限分别为 232、212、213、219、255。零号占位不进入运行对象。名称、图标、行序不能替代身份。

## 来源与字段

本地冻结研究为 `../research/mhp3/armor-catalog-20261026/`，包含实际探针、原始结果、错误记录、Wiki 页面和逐项 crosswalk。构建器不连接宿主机或网络。原生版本以该专题 manifest 和程序 SHA-256 为准；原程序和大二进制不复制进仓库。

40 字节记录由已验证的原生防具访问器取得。`+4` 的低两位为性别，`0x0c` 为近战／远程适用性，`0x10` 选择强化增长表，不能把它解释为职业限制。`+5 + 1` 为稀有度，`+12` 为基础防御，`+18` 为孔位。五耐性为有符号字节，火、水、雷、冰、龙的偏移依次为 **13、14、15、17、16**。

最大防御依本作 `0x0885e12c`／`0x0885e1c8` 的边界与增长计算。`+21..24` 为四段边界；最大等级索引为边界最大值减一，限制到 0～63。增长表 `0x0897d950` 按 `0x10` 选择 `[2,2,3,4]` 或 `[2,3,4,5]`。具体循环见 `tools/mhp3/build_armors.py::decode_stats`。不复用 P2G 的强化公式。

制作表 `0x0899fe68`、步长 36、类型 255 终止。输出为 `+0` 类型与 `+2` 小端编号，四组材料为 `+4,+8,+12,+16` 的 `u16 itemId / i16 quantity`；保留顺序。制作费用直接读取防具 `+8 u32`：实际制作消费者在防具类别跳过半价分支，不能套用装饰品或其他作品的费用算法。剩余出现条件字段未解析，端材不混入材料清单。

1,104 条原生配方均能绑定已有道具。两件训练奖励耳饰的条件采用 P3 日文 Wiki 第 86／90／165 页；24 件耳饰按第 86 页明确的训练所专用表分类，“迅食耳饰”仍为取得未确认。Wiki 中个别错字保留显式映射，并以部位、技能和材料交叉核对；不全局模糊合并。默认收录 1,106 件正常条目，特殊用途 24 件、未知 1 件可筛选或直接定位。

已有 776 条审定中文保持原样，新增 355 条为项目译名。套装成员采用 220 页明确的成员表；男女变体分组，职业变体分行，无系列证据者单列。套装总值取一条可同时穿着的职业行，不把互斥行或男女记录相加。名称和成员审阅、Wiki 获取时间／哈希、原生与第三方逐字段冲突均留在私有研究目录。

## 构建与恢复

离线命令：

```sh
python3 -B -m tools.mhp3.build_armors <当前完整P3库> <冻结研究目录> <review.json> <全新输出目录>
```

构建验证输入／底库哈希、原名绑定、审定名保留、完整身份覆盖、负点及复制标记、配方顺序、全部外键、套装性别／职业互斥与成员覆盖。输出完整库副本、`audit.json` 和成功 `manifest.json`；失败标记 `FAILED.txt`，不得安装失败产物。新表为 `p3_armor_recipes/materials/sets/members`，技能预览和完整详情都从既有防具表读取。

`armor_schema=mhp3-armors-v1`，防具和技能资料版本采用 review 哈希；其余业务表、道具名称绑定及词典不变。旧技能构建器遇到完整防具库会拒绝降级；若重建技能，应从防具扩展前的完整基线重建，再重新审计并追加防具，不能覆盖已安装完整库。

安装前关闭应用及数据库连接，确认当前库仍等于基线，备份并校验候选 manifest／完整性，再同目录临时文件原子替换。异常恢复备份，重启应用并只读回查。实际备份位置、安装哈希和验收环境见专题交接；P3 数据及图标仅获准本地使用。

## 接口与兼容

`ArmorCatalogGameId`、严格 P3 schema 与 repository 贯通现有四个防具 IPC。混合身份、跨作请求和各部位越界编号会被拒绝。收录范围为 `obtainable/unknown/special/all`，直接目标可超出默认范围。名称、日文、别名、编号、技能和材料均可检索，关联命中带原因。

技能详情通过 `p3.armorCatalog` 声明 `full/preview`，旧技能库保留最小预览，新库打开完整防具抽屉。旧 `skills?...&equipment=<armorKey>` 链接按能力升级定位，保留返回技能入口。正文关联开一级抽屉，抽屉内关联先关闭再定位；P3 没有存档写入按钮。
