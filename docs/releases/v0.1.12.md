# v0.1.12

本版加入 MHP2G 七类图鉴、六槽配装器和 PPSSPP 存档编辑。Windows 包内置新版运行资源 v5，解压即可使用；前三作继续沿用共享组件与编辑流程。

## P2G 图鉴与配装

- 道具、怪物、任务、技能、装饰品、武器、防具图鉴，支持搜索、筛选与关联详情。
- 收录 1,501 把武器、2,081 件正常防具；装备选择复用图鉴列表和详情组件。
- 六槽手动配装、逐件装珠、自动配装、任务队列、历史结果复核及撤销。P2G 无护石。
- 已验证“达人 +2、高级耳栓、斩味 +1”目标可以求解，并整套加入存档装备箱。

## P2G 存档编辑

- 支持已确认的日版／汉化版 PPSSPP 存档格式，选择 `MHP2NDG.BIN`，同目录需要 `PARAM.SFO`。
- 支持金钱、波凯点数、游戏时间、道具箱、正常装备箱、装饰品与装备强化，以及导入导出、撤销和重做。
- 保存时成对更新 BIN/SFO，并备份和回读；另存为复制完整存档目录，拒绝选择原目录，避免误覆盖。
- 修复切换角色后旧撤销／重做历史串用的问题；共享操作提示不再遮住抽屉应用按钮。
- 角色名、性别和 HR 保持只读；猫、任务进度、特殊装备及弩附件切换未开放。

## 资源与验证

- 运行资源 v5 包含四作游戏数据库、独立道具译名词典、P2G 存档格式参数、2,400 张内容哈希图标及应用图标。
- 发布检查核对四作词典身份、数据库完整性、P2G 装备身份及图标、打包后文件一致性；Windows 构建另检查 Electron 原生 SQLite 模块与 EXE 图标。
- 应用侧已完成真实存档隔离副本的修改、保存、重开和完整 payload 比对，原件未改；**PPSSPP 游戏内加载、保存后再读尚待实际测试**。
- 发布包不包含个人存档、研究输入、研究报告或自动配装历史。

## 更新与试用

下载 `mh-save-editor-v0.1.12-windows-x64.tar.gz`，完整解压到新目录，运行 `MH Save Editor.exe`。普通使用无需另下资源包；源码开发者请更新到 [运行资源 v5](https://github.com/AlexQFMM2/mh-save-edit/releases/tag/runtime-assets-v5)。

P2G 首次实测建议复制整个存档目录后打开，或使用“另存为”输出到新目录。在 PPSSPP 里读入修改副本、检查修改项并正常保存，退出重进后再用修改器读取。BIN 和同目录的 PARAM.SFO 必须一起使用。
