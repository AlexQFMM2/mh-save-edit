# v0.1.10

修复 MH4G 部分防具无法参与自动配装、无法从图鉴写入存档，以及道具箱和装备箱翻页按钮被格子遮挡的问题。

## MH4G 防具与配装

- 补齐 1,693 条防具的存档编号映射，纠正 18 条旧映射；中文名称继续以 Dex 为准。
- 使用原生属性、完整技能点和明确的性别身份核对映射，避免中文译名差异导致合法防具被排除。
- 分开处理活动防具的男女存档编号，并兼容旧配装的重新加载。
- Dex 收录的 32 条美版专属防具保留展示和说明，不作为 MH4G 可写入装备或自动配装候选。

## 道具箱与装备箱

- 窗口高度不足时，箱内格子独立滚动，翻页按钮保持可点击。
- 保留键盘定位及统一滚动条样式。

## 验证

- 类型检查、完整测试、运行数据审计与生产构建通过。
- 原问题中的四技能组合在测试条件下能找到合法配装；原用户未提供武器、护石等完整条件。
- 道具箱、装备箱在六种窗口尺寸下通过实际点击翻页和键盘定位检查，包含 1366×768 与 3440×1440。

## 社区开发

- Windows 版本及独立运行资产公开下载，运行数据库与图标不再需要私有仓库密码。
- 公开仓库与 fork 可使用同一套运行资产完成测试和打包，开发步骤见 README。
- Dex、ROM、存档和研究中间文件不包含在发布包中。

## 更新方式

下载本版本的 Windows x64 压缩包，解压到新目录后运行 `MH Save Editor.exe`。请使用整包更新，确保防具资料与程序版本一致。个人存档仍从原位置打开，应用会在写入前备份。
