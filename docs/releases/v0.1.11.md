# v0.1.11

修复 MH4G 发掘装备再次打开时无法显示已有参数、看起来需要重新编辑的问题，并在装备箱中标识发掘装备。

## MH4G 发掘装备

- 按装备类型和存档编号识别发掘武器、防具，正确显示名称，并支持在装备箱中按名称搜索。
- 已有发掘装备默认进入“编辑实例”，读取当前装备的完整记录，回填攻击档、属性、斩味、强化等已保存参数。
- 补齐实例编辑所需的参数选项；资料读取失败时显示错误并阻止应用，避免误走普通装备编辑。
- 装备箱详情显示当前实例参数，与编辑器共用字段解释；未知参数保留原值。
- 编辑仍需显式应用，取消不写入；“替换装备”作为独立操作，从模板初始值创建装备。

## 装备箱标识与布局

- 发掘武器和防具的格子左上角增加绿色圆圈、白色“挖”字；这些格子的编号移到右下角。
- 收窄道具字段样式的作用范围，避免影响装备详情；发掘参数面板随可用宽度调整列数。

## 验证

- 合成存档覆盖界面修改、保存文件、重新打开及参数回填，验证完整 28 字节记录、固定装饰珠与未知字节的保留。
- 回归覆盖同名装备、首屏之外的模板、不同装备类型使用相同编号、取消不写入及选项读取失败。
- 核对现有运行资料中的 435 个发掘武器模板和 1,250 个发掘防具模板均可按编号识别。
- 在 1024×620、1366×768、3440×1440 窗口下检查详情、编辑抽屉与“挖”字标记，确认无横向溢出、应用按钮可见、标记不与编号重叠。
- 验证包括合成存档的程序回读，未进行修改后存档的游戏内加载验证。

## 更新方式

下载本版本的 Windows x64 压缩包，完整解压到新目录后运行 `MH Save Editor.exe`。读取原有 MH4G 存档后，可直接查看发掘装备参数；编辑时先应用到草稿，再保存文件。

开发者继续使用公开运行资产 v4，无须重新生成资料库。发布包不包含个人存档或研究中间文件。
