# v0.1.17

新增 MHP3 配装器：原生装备候选、手动护石、自动配装与整套写入存档。

- P3 侧栏「配装器」可用，七槽（武器、头胸腕腰腿、护石）候选来自本作图鉴，支持技能／稀有度／孔位／近远程／性别筛选。
- 护石按原生鉴定规则判定：品级由 `rank + 2×孔数` 推导，技能点数、第二技能与孔位可达性均按原生数据核对；结果给「已确认自然／风险」两种状态，而不是笼统的未知。
- 自动配装按原生规则枚举护石候选（上限保护），结果回填前按当前资料版本复核。
- 可将整套配装写入已打开的 P3 存档装备箱空位；先预览目标格，写入进入撤销历史，不修改穿戴引用。
- 运行资源升级到 v8（新增护石规则表），安装包已内置；旧 v7 保留。

下载 **`mh-save-editor-v0.1.17-windows-x64.tar.gz`**，完整解压到新目录运行。源码开发者可使用[运行资源 v8](https://github.com/AlexQFMM2/mh-save-edit/releases/tag/runtime-assets-v8)。
