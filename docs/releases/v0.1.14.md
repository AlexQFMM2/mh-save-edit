# v0.1.14

更新 MHP2G 装饰品译名，图鉴、道具词典、技能关联和配装资料使用同一套名称。

- 全部 168 颗装饰品已核对孔数和完整正负技能点。37 颗调整根名，例如“流水珠→耐水珠”“大炮珠→炮术珠”；13 颗仅补孔数后缀，共更新 50 个显示名。
- 同名珠子用 `【1】/【2】/【3】` 区分孔数。缺少完整对应的珠子保留本作根名。
- 原日文、旧汉化名及此前项目译名继续可搜；用旧名也能反查制作材料，命中结果显示当前名称。
- 保留本作 ID、孔数、技能点、配方和存档编码。名称用词一致不合并跨代物品，也不改变游戏效果。

下载 **`mh-save-editor-v0.1.14-windows-x64.tar.gz`**，完整解压到新目录，运行 `MH Save Editor.exe`。包内已包含运行资源 v6，普通使用无需另下资源包。源码开发者可使用 [运行资源 v6](https://github.com/AlexQFMM2/mh-save-edit/releases/tag/runtime-assets-v6)。

同批 [MHP2G 中文插件 test.4](https://github.com/AlexQFMM2/mh-save-edit/releases/tag/mhp2g-zh-v0.1.0-test.4) 同步上述译名及相关教程／对白，需另外安装到 PPSSPP；修改器更新不会自动替换插件。

相关回归、完整资料查询、字库／文本解析和重复构建检查通过；本轮新译名的游戏内排版和运行效果待实测。
