# v0.1.16

运行资源升级到 v7，MHP3 日版图鉴与存档编辑随包可用，不必再手动安装 P3 资料。

- 包内新增 MHP3 日版正文库、ULJM05800 存档格式参数和 474 张原生图标，安装后即可打开 P3 图鉴与「P3 · PPSSPP」存档编辑。
- P3 支持金钱、道具箱与猎人装备箱；装备箱使用本作原生武器、防具和手动护石，含强化、装珠、箱格换位与 45 套预设维护。
- 译名词典加入 P3 道具绑定；P2G／3G／4G／GU 的名称、数值与图标未改，绑定指纹保持不变。
- 运行资产校验、打包前后文件身份与图标内容哈希在 CI 中一并核对；P3 图鉴引用的图标全部随包提供。
- 运行资源说明见 [运行资源 v7](runtime-assets-v7.md)。

下载 **`mh-save-editor-v0.1.16-windows-x64.tar.gz`**，完整解压到新目录，运行 `MH Save Editor.exe`。源码开发者可使用[运行资源 v7](https://github.com/AlexQFMM2/mh-save-edit/releases/tag/runtime-assets-v7)。

本地通过类型检查、公共 Vitest、生产构建、运行资源审计和真实原件成对往返；P3 存档的游戏内效果仍待 PPSSPP 实测确认。
