# v0.1.13

修复 MH4G 发掘武器异常属性的最大值选项，按武器类别提供对应的「扩展最大值」。

| 武器 | 异常属性扩展最大值 |
| --- | ---: |
| 操虫棍、双刀、片手剑、弓 | 1000 |
| 大剑、狩猎笛 | 970 |
| 太刀、大锤、长枪、铳枪、斩击斧、盾斧 | 800 |

- 修正原「1000」选项在游戏内实际变成 1170、触发超限检查而无法接受任务的问题。
- 已保存的旧超限值显示为「1170（当前超限值）」，用户主动选择并应用后才修改。
- 保留常规档位；扩展选项提供当前武器已核对的最高正值，其他未识别字节仍可原样保留。
- 支持按数值、「最大」「扩展」或英文关键词搜索。

这些扩展值已通过原生属性超限检查回放，不属于正常发掘档位；**实际接任务、战斗与游戏内保存仍待实测**。应用侧已验证字段修改、其他字节保留、显式应用，以及合成存档保存后重新读取。

下载 `mh-save-editor-v0.1.13-windows-x64.tar.gz`，完整解压到新目录，运行 `MH Save Editor.exe`。包内包含运行资源 v5，无需另下资源包。测试时可将修改结果另存为副本，入游戏确认装备面板、任务受理及保存后重读的表现。
