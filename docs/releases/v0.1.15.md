# v0.1.15

新增 MHP3 日版 PPSSPP 存档编辑（本地预览），并把 P3 图鉴源码纳入应用；P3 运行资料仍需本地安装。

- 从 P3 总览选择「P3 · PPSSPP」，成对读取 `ULJM05800/MHP3RD.BIN` 与同目录 `PARAM.SFO`。角色名、性别和游戏时间只读，猎人等级显示未知，金钱 0～9,999,999 可写。
- 道具箱与猎人装备箱按取得的收纳书显示 800、900 或 1,000 格，支持全箱搜索、复制、清空、换位、CSV 和同格式完整备份；写入范围限于已开放箱页。
- 装备箱使用本作原生武器、防具与手动护石，支持强化次数和装珠。换位维护穿戴引用与 45 套登记预设；已穿戴装备需先在游戏内卸下才能删除或跨部位替换。
- 保存成对备份、写回并回读校验，中断由日志恢复；另存为在所选父目录新建 `ULJM05800` 并复制现有图片。
- 本包只包含运行资源 v6（P2G、3G、4G、GU／XX）。**P3 数据库、存档格式资料和原生图标尚未授权公开发行**，公开包内不含这些文件；P3 图鉴与存档编辑需本地安装 P3 资料后使用，缺少时页面显示缺资料提示，不影响其他作品。
- 内部整理：新任务交接移至 `docs/handoffs/`，与源码同分支保存；既有计划与验收记录保持原路径。

下载 **`mh-save-editor-v0.1.15-windows-x64.tar.gz`**，完整解压到新目录，运行 `MH Save Editor.exe`。

本地通过类型检查、公共 Vitest（138 个文件）、生产构建、真实原件 BIN／SFO 逐字节往返与独立探针核验；P3 存档的实际游戏内效果待 PPSSPP 实测确认。
