# P2G 怪物图标提取

输入为已固定哈希的日文 P2G 展开目录、私有资源目录索引和私有密码算法参考。使用只读 SSH 在宿主机内存解析，输出仅含独立 PNG 和最小来源/映射；不复制 BOOT、DATA、TMH 或完整图集。产物不得进入 Git。

## 已核对调用链

1. 原生日文文本包表 17 是怪物说明，查询入口为 `0x08851594`。
2. 唯一的详情绘制调用者位于 `0x0881A8F0`；条目索引同时选择说明和 `0x0892E2E0` 的 62 条、每条 14 字节的怪物列表定义。
3. 定义的第 1/2 字节是图片坐标，第 3 字节是原生怪物 ID；详情调用 `0x08830078` 绘制图片。
4. 绘图函数绑定资源标记 11（`COCK_TMH`）、纹理 `0x8002`，读取 36×36 像素，游戏内显示为 51×51。资源对应已验证的 DATA 成员 5323，第 2 张纹理。
5. 详情的大/小尺寸记录查询同时使用 `0x08998FF0` 的原生族群指针表。目录中没有独立条目的变体，仅在该族群恰好有一个图鉴代表时复用代表图标；保留 `native-size-family` 依据，不声称有独立亚种图片，不合并怪物身份。

当前固定快照覆盖 84 条怪物身份、62 条游戏图鉴定义、54 张独立图片；另有 6 条非怪物/占位记录。完整逐条映射和哈希保存在私有 manifest，不放在本文档中。

## 重建

```sh
python3 tools/extract_mhp2g_monster_icons.py \
  --host '<已登记的只读 SSH 主机>' \
  --game-root '<宿主机日版展开目录>' \
  --cipher-reference '<私有固定算法参考>' \
  --toc '<私有 toc-probe.json>' \
  --output '<新的私有研究目录>'
python3 tests/mhp2gMonsterIcons.test.py
python3 tests/mhp2gItemIcons.test.py
```

提取拒绝源哈希变化、越界裁切、重复身份、不对称族群或一组多图鉴代表。输出目录必须不存在。合成测试只验证身份完整性和歧义拒绝；真实快照的全量覆盖由私有审计核验。
