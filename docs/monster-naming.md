# 怪物中文名称与旧名搜索

2026-10-21 用户确认：同一只怪物采用已确认的较新作品官方简中称呼；本次将《崛起》的 **奇怪龙** 用于 `Khezu / フルフル`，兼容旧称 **白电、白电龙**。名称依据为本次用户提供并确认的用词，不将项目衍生名称标成官方逐字译名。

GU、4G、P2G 的怪物主名及关联显示已同步。GU／P2G 中明确使用“白电”的任务、材料、装备、猎猫装备与说明采用同一称呼；P2G 插件同步怪物名、装备名、说明和对白，共修订 176 个文本单元。4G 的旧主名“电龙”仅按 `Khezu / フルフル` 身份及其任务关系修正；4G 搜索旧名“电龙”仍可找到它。红电亚种保持独立身份，GU 的 `Astalos / ライゼクス` 仍为“电龙”。

显示与搜索用词由 [monsterNaming.mjs](../api/catalog/monsterNaming.mjs) 提供。怪物、装备、任务及猎猫入口兼容“白电／白电龙”；词典保存旧名称别名。P2G JSON 显示名的旧值保存为 `nameAliases`，日文、原名证据、ID、技能点、配方、数量和数值不改。原文明示 `フルフル亜種` 的文本保持亚种区分；只有原文确认指向本体的说明才同步旧称“电龙”。

运行资料的最后构建阶段执行：

```bash
node tools/repair_runtime_catalog.mjs
node tools/audit_runtime_catalog.mjs
```

[名称迁移](../tools/runtime/monsterNames.mjs)只处理应用的显示字段、明确的 JSON 显示键及搜索索引；原 Dex 表、日文、来源／原始证据字段保持不变。它先验证词典与原资料的身份指纹，再更新配套指纹；旧规范搜索文本保留，同时增加新名索引。词典构建器亦复用相同显示规则，冻结旧官汉输入可以与新审阅名称共同重建，来源明确记录为项目命名规则。

本地生成库、插件包、备份、哈希及交付验证统一保存在[计划归档](../plan/archive/2026-10-24/mhp2g-records/monster-naming-delivery.md)。
