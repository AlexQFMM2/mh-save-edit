# P3 装饰品图鉴

在 P3 工作区选择“资料 → 装饰品”。页面直接读取与道具图鉴相同的 `data/mhp3.sqlite`，沿用其中审定名称、日文、别名、图标、孔数、技能点和全部制作路线；无需另建数据库或重新安装图标。

支持中文、日文、旧称、十进制／十六进制道具编号、技能中英日文和制作材料名称搜索。技能／材料命中显示原因；技能下拉可用中英日文搜索。P3 的技能筛选包含正负点数，标签明确说明，按技能筛选时默认按点数降序。孔位可选 1～3 孔。列表选择不重新查询或重置滚动，筛选与选中记录在 URL 中。

同名珠保留不同 P3 编号，列表、详情和关联入口保留完整正负点数，负技能另有文字标签。制造费用和配方出现条件尚未收录；孔数和技能点使用 P3 原值。完整发动效果见[技能图鉴](skill-catalog.md)。

正文点击材料打开道具详情抽屉，点击技能打开完整技能详情抽屉。道具正文中的珠用途和“查看装饰品详情与技能”打开装饰品详情抽屉。抽屉内再次点击关联对象时先关闭，再跳转对应图鉴并定位；点技能进入技能页，点防具进入技能页内的最小关联预览。缺少技能资料时显示安装提示。

接口使用 `DecorationCatalogGameId` 和 `{ gameId: 'mhp3', itemId }`，不使用 `saveId`。合法范围内的普通道具请求装饰品详情返回空；混合身份、跨作身份和越界编号被拒绝。全局 `CatalogGameId` 及配装／存档服务不扩大。

运行数据缺失或配套词典不一致时沿用道具库的明确提示；列表、筛选和详情错误可重试。数据库准备、命名规则、恢复和私有资料边界见[道具构建说明](item-catalog.md)，本轮验收见[装饰品交接](../../plan/mhp3-decoration-catalog/handoff.md)。此入口只读，不提供写入存档。
