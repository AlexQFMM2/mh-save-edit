## 下一阶段：P2G 配装器

从当前 `catalog-armor-v1` 读取已验收的武器、防具、珠和技能，优先复用共享配装页面、计算器、选择核心组件、会话草稿及主进程自动搜索服务。接入顺序为：本作规则与原生身份适配 → 手动六槽配装／装珠 → 自动配装与历史结果 → 四作回归验收。具体交接见[配装器接入说明](mhp2g-loadout-handoff.md)。

无护石会省去编辑器、自然生成规则及搜索候选维度，但当前配装模型和搜索仍依赖存档编号，并默认七槽，不能只隐藏护石按钮后开放入口。需保留 P2G 原生武器／防具键及珠的 `itemId`，核对正负技能阈值、胴系统倍加（含胸部珠）与职业／性别适用性；计算和自动搜索不能被尚未验证的存档编码阻断，也不能伪造“可写入存档”。

只读图鉴已完成本地交付。长篇说明译文、存档编码与写入、完整游戏中文补丁继续独立安排；逐级强化材料、全部制造／进度解锁和未完整追踪的奖励程序分支不作为首版逻辑配装前置。配装展示基础／最终最大防御，不据此承诺当前存档进度可取得或强化到上限。

- 正常目录和占位／隔离理由可追溯；正常条目具有审阅后的中文名、日文原名、双语搜索与来源，图鉴键保持稳定，不构造 Dex ID 或存档 ID。
- 展示字段有本作证据，未知保持未知；套装分组、技能点、图标及材料端点无错绑或悬空，旧道具用途有明确对应。新旧全量对比保留原有图鉴、武器译名与词典绑定，另外三作保持可用。
- 图鉴正文关联打开唯一一级 portal 抽屉；抽屉内关联先关闭再跳转定位，不能嵌套。技能旧定位链接、刷新恢复、搜索命中原因及键盘操作一并验证。
- 选中条目与详情页签只请求必要详情，不重新查询整列表／套装；待返回响应读取最新选择，避免自动首选覆盖新导航。连续选择、滚动位置、窄窗口和抽屉开关不改变正文位置的行为需回归。
- 组件独立 `.tsx`／`.css`，下拉统一 `SearchableSelect` 并提供显示名称及双语关键词，筛选标签水平排列；沿用全局字号、文字／数据颜色和滚动条令牌，遵守页面与组件 CSS 边界。
- 日文有明确对应时优先采用 GU 官汉，无对应时保留项目译名来源；跨代同名或效果相近不合并身份，不把 GU 机制复制到 P2G。沿用 P2G「大砲珠」的“大炮珠”名称。
