## 接入位置与验收方向

现有入口为 `api/catalog/decorationRepository.ts`、`api/catalog/types.ts`、`api/catalog/schemas.ts`、`api/catalog/ipc.ts`、`desktop/preload.ts`、`ui/env.d.ts`、`ui/App.tsx` 和 `ui/pages/DecorationCatalogPage/`。列表、筛选、详情、材料、技能和抽屉组件位于 `ui/components/Decoration*/`。

旧三作装饰品接口以 `GameId` 和 `saveId` 为主；P2G 接入须先确定独立图鉴身份，不能仅扩大类型后把原生编号填进 `saveId`。可参考 P2G 道具／怪物／任务的独立 repository 分派，不扩大存档编辑与配装支持范围。材料关联传完整 `ItemIdentity`，P2G 使用 `itemId`；道具制作用途需反向定位装饰品。

复用既有装饰品布局、分页和水平紧凑 `SearchableSelect`，支持中文、日文及相关关键词搜索。正文关联打开唯一一级抽屉；抽屉内关联关闭后跳转定位。新增组件各有 TSX/CSS，使用全局字号、数据色和滚动条规则。

验收至少覆盖身份唯一、数值与来源逐项一致、材料／技能端点闭合、正负技能点、未知值、关联反查、跨游戏身份拒绝、旧库缺资料提示、异步切换、单层抽屉及旧三作回归。构建先写新目录并审计，确认道具／怪物／任务与词典兼容后，备份并原子安装；不自动关闭应用。
