# P2G 逻辑配装器

2026-10-13 完成。[交接范围](../../plan/archive/2026-10-24/mhp2g-records/loadout-handoff.md)与[实施前阻塞核查](../../plan/archive/2026-10-24/mhp2g-records/loadout-preflight.md)保留来源和决策依据。P2G 的 `/game/mhp2g/edit/loadout` 已开放，不依赖打开存档；[存档入口](save-editor.md)也已开放，整套配装可加入当前角色装备箱。最新状态见[整体验收](../../plan/archive/2026-10-24/mhp2g-records/acceptance.md)。

## 玩法与交互

- 武器、头、胸、腕、腰、腿六槽，无护石编辑、筛选、贡献列或搜索阶段。
- 手动与自动选装共用四作的 `EquipmentPickerContent`：左侧紧凑候选、右侧完整图鉴详情，各自独立滚动，分页与应用底栏固定。支持名称／日文、类别、稀有度、孔位等筛选和分页，保留名称来源及原生详情。点击、Enter、Space 只改变预览；底栏应用才提交，关闭／Escape 放弃选择并返回触发焦点。
- 装珠每一步即时计算、记录撤销；关闭不回退。手动性别／职业冲突和超孔允许保留，在装备行及诊断中提示。
- 关联点击关闭唯一工作抽屉后跳转对应图鉴。自动搜索编辑装备在同一抽屉切换子视图，Escape 返回条件。
- 草稿、撤销和搜索条件按游戏保存于当前会话。离开页面不清空；重启不承诺保留手动草稿。导入或资料更新后按当前目录重读数值，失败保留原草稿及历史。
- 自动配装仅选择正向发动技能，保留负点和负面发动。没有额外“禁止负面发动”约束。搜索必须选择具体武器，支持固定装备／连珠固定；最终 P2G 结果必须适用且满足目标。

## 身份与计算

`api/loadout/p2gRepository.ts` 从现有四个 P2G 图鉴仓库生成计算快照；不新造装备数据库、护石表或存档 crosswalk。`dataVersion` 包含当前构建来源元数据和适配规则版本。

武器使用 `weaponKey`，防具使用 `armorKey`，珠使用 `gameId: mhp2g` 与 `itemId`。P2G 的 `saveType/saveId/dexId` 保持空值，拒绝发掘模板、原始存档实例、护石及跨游戏珠；存档层通过已验证的原生类型与索引转换写入，不在逻辑配装中伪造后作身份。

自然合法性与存档结构可编码性分开：已确认的 P2G 记录可编码，编码结果为 `encodable`；读取匹配存档后可整套加入箱子。真正的身份／记录结构错误仍可阻断。

技能计算选择实际达到的最强正／负档位；修复共享计算器在负点超过多档阈值时错误选择第一档的问题。胴系统使用本作 ID 1，复制胸甲及胸部珠的正负贡献，不复制其他倍加部位的珠。技能矩阵显示基础贡献、珠、倍加／特殊贡献和总数；复合发动保留说明，不伪造额外技能点。负面发动保留名称并使用警告色。

历史应用先重水合当前装备／珠，再解析当前 `activationKey` 对应的技能阈值并重新计算。旧历史中的技能点、防御或目标阈值不能绕过复核；失败保留记录、显示原因。

## 任务生命周期

继续使用 `AutoLoadoutJobService` 与同一个编译 Worker。全局单 Worker，跨游戏请求排队；条件、进度、结果、终态保存在主进程 `userData/state` 私有库。关闭抽屉、导航离开不取消任务；暂停、继续和取消均为独立操作。重启将未完成任务标记为中断，保留条件供重新运行。

达到结果上限、超时、穷尽当前候选域分别展示，不承诺覆盖所有真实装备方案。P2G 不进入护石生成和覆盖不足阶段；三作既有固定风险输入行为保持兼容。
