# MHP2G 中文插件测试步骤

先按 `README.zh-CN.txt` 安装，使用备份后的游戏存档，从游戏冷启动进入。这里的“通过”需要实际操作和显示结果；看到部分中文不能代替全部测试。

## 第一轮：确认加载与常用页面

1. 正常读档进入村庄，确认角色名、猫名、日文和符号显示正常。
   从 test.2 更新后，先确认全新的 `plugin.log` 中构建标识与本包 README 一致、`font_metrics` 包含 `ready=1 active=1`；实际查看中文后再继续。日志正常仍需要画面验证。
2. 打开房间装备箱，检查更换装备菜单；查看多种武器、防具，以及常用道具的名称和说明。
3. 来回切换列表、详情和分页，观察是否缺字、乱码、文字重叠、越框或卡死。覆盖范围以同包 README 为准，遇到残留日文时记录具体位置。
4. 访问村长、集会所、商店、农场、猫厨房和床边 NPC，查看选项及多页对话；翻页和选项行为应保持正常。新译长文需重点检查句意、专名和分页。

## 第二轮：实际游玩与保存

1. 查看村庄与集会所的任务列表和详情，检查任务名、目标、失败条件、说明、主要怪物和委托人；切换多个任务及分页，确认内容对应当前任务。
2. 打开教程和训练所，检查说明与任务详情；退出后重新进入，检查是否仍有中文或出现显示异常。
3. 完成一次正常任务流程：接取、出发、游戏内操作、结算和回村；核对出发前与任务中的文字，并记录残留日文的位置。
4. 游戏内正常保存，完全退出 PPSSPP，再重新启动游戏读档，确认进度、装备及动态名称正常。
5. 继续游玩和重复访问菜单，记录任何崩溃、异常变慢或显示损坏。一次正常启动不能证明长期稳定。

## 第三轮：停用与回退

1. 完全退出 PPSSPP，把插件文件夹移出 `PSP/PLUGINS` 后冷启动，确认界面恢复日文、存档仍能读取。
2. 完全退出后放回完整插件文件夹，再冷启动，确认中文重新生效。

## 反馈格式

```text
补丁版本：
PPSSPP 版本／操作系统：
完成的测试步骤及结果：
问题场景与复现步骤：
首次出现还是重复出现：
是否冷启动、是否使用即时存档：
```

退出后保留 `plugin.log` 和 `plugin.previous.log`。缺字、排版或错译请附具体页面；加载失败或崩溃则先提供复现步骤与日志。手机、PSP 实机和联机测试请单独注明，不能沿用 Windows 小样的验收结果。
